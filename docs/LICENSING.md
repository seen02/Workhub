# 라이선스와 저장소 이용 범위

이 저장소는 기술 검토를 위한 Workhub 공개 소스 사본이다.

## 현재 적용 방침

1. 저장소 전체를 MIT, Apache 2.0 등 하나의 오픈소스 라이선스로 재허락하지 않는다.
2. 프로젝트별 작성물에는 이번 업로드로 새로운 이용 허락을 부여하지 않는다. 권리는 각각의 정당한 권리자에게 있으며, 기존 라이선스·별도 계약·법률에 따른 권리는 유지된다.
3. Outline 수정·파생 부분에는 사용 버전의 원래 BSL 1.1과 파라미터를 유지한다. [원문](../unified-work-assistant/integrations/outline/LICENSE)을 함께 제공한다.
4. Rocket.Chat의 MIT 적용 영역과 Enterprise 영역을 구분한다. 다른 제3자 구성 요소도 원래 조건을 따른다.
5. 리포지토리 계정 소유자와 모든 코드의 저작권자가 동일하다고 주장하지 않는다.

## 공개 또는 별도 라이선스 부여 시 확인할 사항

- 회사·현장실습·공동 작업 결과물의 권리 귀속과 공개·재허락 권한.
- 기존 `Outline/local-ai`, `ai-agent-main/ai-agent-main`의 작성자와 원래 조건.
- 독립적으로 작성하고 권리를 보유한 코드와 제3자 파생 코드의 파일별 범위.
- 코드·문서·이미지·모델·전이 의존성 각각의 라이선스와 고지.
- 비밀키, 계정, 원문·채팅, 첨부, DB 및 Git 이력의 공유 적합성.

권한과 출처를 확인한 자체 코드에는 이후 별도 범위를 정해 MIT 등을 선택할 수 있다. 이 경우에도 Outline 파생 부분을 포함한 제3자의 조건을 변경할 수 없다.

## 포트폴리오 소개

Rocket.Chat·Outline 기반이라는 사실과 본인의 실제 담당 범위를 구체적으로 설명한다. 기존 메시징·문서 편집·실시간 협업 기능과 Workhub에서 추가한 업무 보고 연동·업무 등록·칸반·진행 통계 등을 구분한다. 회사 자료와 개인정보가 없는 합성 데이터로 화면을 준비한다.

비공개 소스의 접근권, 복제권, 배포권을 채용 담당자에게 자동으로 부여하지 않는다. 포트폴리오나 면접 자료의 허용 범위는 소스 공개·라이선스 부여 권한과 별도로 확인한다.

주요 원문과 구성 요소별 출처는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)를 참고한다.
