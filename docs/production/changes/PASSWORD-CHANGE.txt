비밀번호 변경 버튼 — 2026-10-27

사용 위치: 개인 설정 → 프로필 → 비밀번호 변경.
새 탭에서 Authentik의 기본 비밀번호 변경 화면을 엽니다.
기존 Authentik 인증 흐름에서 본인을 확인한 뒤 변경 화면으로 이동합니다.
기본 구성에서는 아이디·현재 비밀번호를 확인하며, 만료된 세션도 다시 로그인합니다.
실제 비밀번호 입력·정책 검증·저장은 Authentik이 담당합니다.
Outline에는 비밀번호나 관리 API 토큰을 추가하지 않습니다.

주소는 기존 OIDC_ISSUER_URL(우선) 또는 OIDC_AUTH_URI와 URL에서 자동 계산합니다.
VM의 /authentik/ 프록시 경로와 공개 포트를 유지합니다.
Authentik은 상대 next 주소만 허용하므로, VM의 같은 출처 구성에서는
변경 후 /settings로 복귀합니다. 별도 도메인 구성에서는 Authentik의
애플리케이션 실행 경로를 통해 Outline으로 돌아갑니다.
수동 OIDC 주소만 설정된 별도 도메인 구성은 Authentik 사용자 화면으로 복귀합니다.
기본 default-password-change Flow와 사용 중인 기본 인증 Flow가 필요합니다.

새 환경변수와 DB 마이그레이션은 없습니다. Workhub 수정도 없습니다.
VM에는 배포하지 않았습니다. 기존 .env·Compose 프로젝트·볼륨을 유지하고
이 폴더에서 Outline만 다시 빌드·교체하세요:

  docker compose build outline
  docker compose up -d --no-deps outline
  docker compose logs --tail=60 outline

변경 파일:
  outline/app/scenes/Settings/Profile.tsx
  outline/server/env.ts
  outline/shared/utils/authentik.ts
  outline/shared/utils/authentik.test.ts

기존 프로필의 사진·이름·이메일·저장 기능과 분리된 버튼입니다.
Authentik OIDC 설정을 판별할 수 없으면 버튼을 표시하지 않습니다.

검증: 로컬 TypeScript 검사·프로덕션 빌드·주소 계산 테스트 11개 통과.
일반 직원 계정으로 기존 세션·만료 세션 재인증 후 비밀번호 입력 화면 도달 확인.
실제 비밀번호는 변경하지 않았습니다. 로컬 서비스 헬스 및 배포 링크 확인.
브라우저 UI 자동 확인은 도구의 현재 URL 식별 실패로 중단됐습니다.
