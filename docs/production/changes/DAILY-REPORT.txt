반영한 기능
- 날짜 제목과 보고 표를 인식하고 기존 Outline 토글로 접기·펼치기.
- 날짜 옆 ⋯에서 오늘 보고 추가, 미완료 업무 선택 이월, 하위 문서로 이동.
- 같은 날짜 중복 생성 방지 및 이월 항목 중복 방지.
- 작업자별 화면 필터. 필터는 보고 원본이나 다른 이용자의 내용을 바꾸지 않음.
- 이 날짜 보고 삭제: 해당 날짜 제목 및 표를 포함한 보고 구간을 함께 삭제. 편집기 실행 취소 지원.
- 관리자 전체 설정: 설정 → 워크스페이스 → 세부 정보 → 업무보고 도구 사용.
- 문서별 설정: 문서 ⋯ → 업무보고 도구 토글. 켜기/끄기 두 상태만 제공.
- 토글 스타일을 기존 설정과 통일하고 날짜 메뉴의 hover 배경 넘침 수정.

사용 조건과 기본값
- 컬렉션에 게시된 문서의 날짜 제목 아래, 첫 열이 작업자/담당자/이름인 표를 인식.
- 미완료 이월은 계속/진행 열의 미체크 체크리스트 또는 [ ] 항목을 사용.
- 변경 작업은 문서 편집 권한이 필요하며 서버에서도 권한과 버전 충돌을 검사.
- 관리자 전체 설정이 꺼지면 문서별 설정보다 우선하여 업무보고 도구와 전용 API를 중단.
- 새 문서는 기본 꺼짐. 설정을 저장한 적 없는 기존 문서는 켜짐으로 해석.
- 이전에 저장된 auto 값은 호환을 위해 받아들이되 켜짐으로 정규화.
- 전체/문서 설정을 꺼도 작성된 본문과 Outline 자체 토글은 유지.

배포 범위
- 이번 작업은 배포용 소스 반영과 소스 ZIP 갱신까지 수행.
- Docker 이미지 빌드·실행 컨테이너 교체·VM 원격 전송/배포는 수행하지 않음.
- Workhub, Authentik, Compose, 환경변수, DB 스키마는 변경하지 않음.
- 예시/안내 문서는 DB 데이터이므로 VM용 소스에 복사하지 않음.
- 새 DB 마이그레이션이나 환경변수 없음. 업무보고 변경만 적용할 때는 Outline만 재빌드/교체.
- 기존 운영 .env와 데이터 볼륨을 유지하고 VM의 기존 Compose 설정을 사용.

VM에서 직접 빌드하는 경우(이 작업에서 실행하지 않음)
docker compose build outline
docker compose up -d --no-deps --no-build --force-recreate outline

이미지 TAR로 배포하는 환경은 기존 VM 이미지 빌드/전송 절차를 사용.
기존 dist/vm-images 및 이미지 TAR에는 이번 변경이 포함되어 있지 않음.
