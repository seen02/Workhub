이전 보고 가져오기 열기 ↗

예전에 채팅으로 쓴 보고도 가져올 수 있어요

새로 다시 입력하지 않아도 됩니다. 단, 지금은 본인이 poc-reports 테스트방에 쓴 텍스트만 지원합니다.

  1. 이전 보고 가져오기 열기 ↗ → 로켓챗 테스트 계정으로 로그인합니다.
  2. 시작일·종료일을 고르고 내 메시지 미리보기를 누릅니다. 최대 31일을 볼 수 있습니다.
  3. 일반 대화는 빼고 보고로 사용할 메시지만 체크합니다. 한 번에 최대 5건입니다.
  4. 선택한 메시지로 AI 초안 만들기를 누르고 기다립니다.
  5. 결과의 내용 확인·수정하기 → 내용을 확인하고 확인하고 저장을 누릅니다.

미리보기는 조회만 합니다. 선택한 메시지만 AI가 처리하고, 확인하기 전에는 최종 보고로 저장하지 않습니다. 이미 가져온 것은 다시 생성하지 않습니다. 다른 사람의 보고·파일·실제 회사 채널은 아직 지원하지 않습니다.

이 경로는 관리 화면에서 확정해야 합니다. 채팅의 ‘확정’으로 저장되지 않습니다. 원문 작성 날짜를 유지하므로, 어제 쓴 보고를 오늘 가져오면 ‘어제 보고’로 찾으세요.

일부 항목만 실패했거나 목록이 더 있나요?

성공한 초안은 유지됩니다. 실패 항목의 사유를 확인하고 필요한 것만 다시 시도하세요. 원문이 바뀌었으면 미리보기를 다시 조회해야 합니다.

다음 메시지 더 보기로 이전 목록을 확인할 수 있습니다. 방 메시지를 50개씩, 한 조회에서 최대 2,000개까지 확인합니다. 한도에 도달하면 기간을 좁히세요.

poc-reports 방인지, 메시지 맨 앞에 보고와 띄어쓰기가 있는지 확인하세요. ‘잠시만 기다려 주세요’가 나오면 AI가 처리 중이니 같은 보고를 반복 전송하지 말고 기다리세요. 안내가 필요하면 도움말이라고 보내세요. 계속 응답이 없으면 로컬 서버·봇 실행 상태를 확인해야 합니다.

저장 또는 조회가 안 돼요

상태 확인 필요 항목은 수정 화면에서 실제 상태를 선택해야 저장됩니다. 조회 결과가 없으면 먼저 확정했는지 확인하고 이번 주 보고처럼 기간을 바꿔 보세요. 수정일이 아닌 원문 작성일 기준으로 찾습니다.

수정 화면 없이도 쓸 수 있나요?

네. 초안이 맞다면 채팅에서 보고 → 확정 → 오늘 보고만 사용하면 됩니다. 수정이 필요하거나 상태가 불명확할 때만 별도 화면을 여세요.

이 내용이 실제 회사 채널에 자동으로 보내지나요?

이 흐름은 로컬 로켓챗 비공개 테스트방에서만 동작합니다. 운영 중인 회사 채널로 자동 발송하지 않습니다. 다만 테스트방 안의 보고와 조회 결과는 그 방의 다른 구성원도 볼 수 있습니다.

화면마다 로그인을 다시 해야 하나요?

로켓챗과 관리 화면의 로그인은 현재 분리되어 있습니다. 같은 테스트 계정을 사용하지만 관리 화면은 새로고침·창 닫기 후 다시 로그인해야 합니다. 기존 웹의 데모 직원 선택은 이 로그인과 다릅니다.

다른 직원 PC에서 링크가 안 열려요

127.0.0.1은 지금 링크를 여는 PC를 뜻합니다. 이 노트북으로 접속하는 공용 주소가 아닙니다. 해당 PC에 환경을 실행하거나 공용 서버 배포가 필요합니다. 실행 안내는 저장소의 TEAM_START.md를 참고하세요.

페이지 자체가 안 열려요

로켓챗은 3000, 관리 화면은 8003, 기존 웹은 5173 포트입니다. 해당 프로그램이 꺼져 있으면 매뉴얼 링크만으로 실행되지는 않습니다. 로컬 서비스 실행 상태를 확인해야 합니다.

이 안내를 읽거나 메뉴를 바꾸는 것만으로 보고가 전송·저장되지는 않습니다. 현재는 로컬 PoC입니다.
