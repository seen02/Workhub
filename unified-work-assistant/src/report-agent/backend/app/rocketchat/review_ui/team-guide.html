내 방에서 준비하고, 보고방에 제출하기

어디서 무엇을 하나요?

기술지원팀 아래의 AI업무비서-개발-project와 공간정보-Agent-project는 프로젝트 논의와 자료 공유 공간입니다. 이 방의 대화는 봇이 자동 수집하지 않습니다.

직원별 개인보고-계정명 방은 카카오톡 ‘나와의 채팅’처럼 사용하는 개인 업무 공간입니다. 참여자는 직원 본인과 report-bot 두 명뿐입니다.

업무보고는 확정 보고 공유와 팀 업무 조회를 함께 하는 공간입니다. 개인 저장만으로는 보고가 올라가지 않습니다.

내 개인보고 방 열기 →

맞으면 한 번 클릭, 고칠 때만 수정 화면

  1. 본인의 개인보고 방에 보고 업무내용을 입력합니다. 프로젝트 이름을 함께 적으면 자동 분류에 도움이 됩니다.
  2. 봇이 먼저 [업무목록] → 날짜·시간 → 프로젝트별 업무·상태만 담은 보고 미리보기를 보여줍니다.
  3. 내용이 맞으면 안내 메시지의 ✅ 이대로 보고를 누릅니다. 개인 저장과 팀 업무보고방 게시가 한 번만 처리됩니다. 키보드로 하려면 보고 입력 후 Enter를 누릅니다.

고칠 때: 별도 안내 메시지의 ✏️ 내용 수정을 누르면 비밀번호 입력 없이 열립니다. 프로젝트·내용을 수정해 내용 저장 → 업무보고방에 보내기를 누릅니다. 자동 로그인 링크는 15분 동안 유효하며 직접 주소로 들어가면 로그인이 필요할 수 있습니다.

여러 초안이 있어도 가장 최근 미게시 미리보기가 현재 보고 대상입니다. 프로젝트·상태가 불명확한 초안, 가져온 과거 보고, 웹에서 수정한 보고는 수정 화면에서 최신 내용을 확인한 뒤 게시합니다.

저장과 게시의 차이

초안: AI가 정리했지만 직원 확인 전입니다.
개인 저장: 직원이 확인한 보고입니다. 팀 보고방과 기존 공용 대시보드에는 자동 반영하지 않습니다.
게시 완료: 직원이 최종 내용을 직접 팀 보고방에 전송한 상태입니다.

채팅에서 오늘 보고라고 입력하면 본인의 저장 보고를 찾습니다. 조회 결과가 있다는 것만으로 팀에 게시됐다는 뜻은 아닙니다.

팀 업무 현황을 묻고 보는 방법

  1. 직원 또는 관리자가 기술지원팀의 업무보고 방을 엽니다.
  2. 오늘 poc-employee 사원 보고 보여줘, 오늘 업무비서 프로젝트 보고 다 보여줘, 공간정보 프로젝트 진행사항 알려줘처럼 자연어로 질문합니다.
  3. 봇 답변의 전체 프로젝트·직원·리스크 보기를 누르면 같은 채널 구성원에게 전체 현황이 별도 비밀번호 없이 열립니다.

Gemma 3는 질문에서 날짜·직원·프로젝트·조회 유형만 해석합니다. 답변은 직원이 확인한 확정 보고 DB를 조회해 만들며 일반 대화와 미확정 초안은 제외합니다.

직원과 관리자가 같은 업무보고 방에서 질문하므로 별도 관리자 채널로 이동할 필요가 없습니다. 과거 관리자-업무비서 방은 기존 대화 보존용이며 봇은 더 이상 처리하지 않습니다.

신입 직원 등록·수정·보안

  • 신입 등록: 관리자는 Rocket.Chat 계정을 만들고 기술지원팀의 업무보고 채널에 직원을 추가하기만 하면 됩니다.
  • report-bot이 구성원 변경을 감지해 최대 약 30초 안에 개인보고-계정명 방 생성, 직원·봇 초대, 처리 대상 등록을 자동으로 완료합니다. 별도 동기화 명령은 필요하지 않습니다.
  • 자동 등록이 지연될 때만 서버 관리자가 수동 동기화 스크립트를 복구용으로 실행합니다.
  • 게시 후 수정은 다시 저장하고 게시 미리보기를 확인해 수정본을 보고방에 게시합니다. 이전 게시본은 유지됩니다.
  • 게시 버튼을 여러 번 눌러도 같은 버전은 중복 게시하지 않습니다.
  • 여러 직원이 동시에 보고하면 실시간으로 접수한 뒤 내부 큐에서 순서대로 처리합니다. Rocket.Chat의 요청 창이 찬 경우에도 보고를 버리지 않고 초기화 시각까지 기다렸다가 자동 재시도합니다.
  • 보고방에는 확인된 항목만 보냅니다. 개인 원문, AI 근거, 수정 이력과 개인보고 방 링크는 보내지 않습니다.
  • 수정 링크는 15분짜리 업무비서 전용 세션을 발급합니다. 직원 비밀번호나 report-bot 인증 토큰은 브라우저에 전달하지 않습니다.
  • 개인보고 방에 다른 사용자가 추가되거나 업무보고 채널에서 제외되면 방과 기록은 남기고 봇 처리만 중지합니다. 서버 관리자의 시스템 접근까지 막는 보안은 아닙니다.
