담당자별 일정 겹침

기간별 동시 배정 업무 · 업무 담당자 기준

시작일~마감일이 겹치는 미완료 업무를 셉니다. 긴 기간은 주별 최대 동시 건수입니다. 실제 작업 시간이나 과부하를 의미하지 않습니다.

전체 업무 상태
숫자는 어떻게 계산하나요?

프로젝트 진행률은 진행률이 입력된 업무들의 평균입니다. 전체 진행률은 집계 가능한 프로젝트 진행률들의 평균입니다. 업무 시간과 프로젝트 규모에 따른 가중치는 적용하지 않습니다.

완료 업무는 상태가 ‘완료’인 업무입니다. 상단 지표와 점검 목록의 미완료는 완료되지 않은 모든 업무이며, 마감 초과도 포함합니다. 담당자 현황은 완료 · 마감 초과 · 미완료(초과 제외)로 나누어 중복 없이 셉니다. 공동 업무는 참여자마다 포함하므로 담당자별 건수의 합이 전체 업무 수와 다를 수 있습니다.

마감 초과는 마감일이 지난 미완료 업무, 마감 임박은 오늘부터 선택한 7일 또는 30일 후까지 마감하는 미완료 업무입니다. 기한 미정은 마감일이 없는 미완료 업무입니다. 마감은 한국 날짜를 기준으로 계산합니다.

프로젝트·담당자 필터에 따라 집계 범위가 바뀝니다. 담당자를 선택해도 공동 업무의 진행률은 업무 전체 기준입니다. 관리자의 담당자 현황은 선택한 프로젝트 범위의 구성원을 함께 보여줍니다. 마감 확인 기간은 진행률의 계산 기간을 바꾸지 않습니다. 확정 전 보고 초안은 통계에 반영하지 않습니다.

조회 조건

마감 확인 기간

Workhub, 이렇게 사용하세요

실무자: 업무 보드 → 내 업무 → 업무 선택 → 진행 보고 → 초안 확인 → 확정.

관리자: 진행 통계 → 프로젝트·팀원 현황 확인 → 업무 보드에서 완료 기준과 담당자 배정.

프로젝트는 함께 일하는 공간, 업무는 해야 할 일, 완료 기준은 그 일을 끝냈다고 판단할 항목입니다. Outline은 원본 문서가 보관되는 곳이며, 평소 보고는 이 화면에서 완료할 수 있습니다.

시연 예시 · 팀장 · 홍길동 · 김철수

프로젝트 팀 협업 시연 → 업무 고객 포털 오픈 준비를 선택하세요. 팀장은 기준·배정에서 이름으로 담당자를 선택합니다.

  1. 계정별로 로그인

    팀장과 실무자의 시연용 계정으로 각각 로그인합니다. 각각 별도의 브라우저 프로필에서 포털에 먼저 로그인하고 Rocket.Chat에 Authentik으로 로그인하세요.

  2. 각 실무자의 통합 업무 비서 개인 대화

    시작을 보내고 팀 협업 시연 버튼 → 고객 포털 오픈 준비 버튼을 누릅니다. 코드를 복사할 필요가 없습니다. 홍길동은 요구사항 정리·사용자 안내 작성, 김철수는 화면 검증·배포 점검 담당입니다.

  3. 홍길동 보고

    요구사항 정리는 진행 중이고 사용자 안내 작성은 아직 시작 안 했어.

  4. 김철수 보고

    화면 검증은 끝냈고 배포 점검은 진행 중이야. → 완료 1/4, 25%

  5. 남은 항목 완료

    홍길동: 요구사항 정리와 사용자 안내 작성 둘 다 끝냈어. → 75%
    김철수: 배포 점검도 끝났어. → 100%

  6. 매번 초안 확인 후 확정

    봇이 보낸 기존 보고 양식을 확인하고 그 초안 아래의 이 보고 확정 버튼을 누릅니다. 확정 전에는 원본이 바뀌지 않습니다. 팀장은 진행 통계에서 이름별 완료 수를 확인합니다.

진행 중에는 완료 점수를 주지 않으므로 첫 보고 후에도 전체 진행률은 0%입니다. 보드는 약 20초마다 갱신됩니다. 다른 업무는 업무 다시 선택, 다른 프로젝트는 프로젝트 변경 버튼을 사용하세요.

다시 처음부터 시연하기

팀장으로 업무의 기준·배정을 열고 네 항목 상태를 모두 예정으로 선택 → 배정 변경안 확인 → 확정합니다. 담당자는 유지하세요. 미착수·0%·완료 0/4가 되면 준비 완료입니다. 실무자 대화에서 현재 업무 · 완료 기준을 눌러 최신 상태를 확인하세요. 과거 채팅과 보고 이력은 유지됩니다.

업무 한 건으로 확인하는 시연

  1. 프로젝트 선택

    시연용 계정으로 로그인하고 상단에서 ‘시연 · 고객 포털’을 선택합니다.

  2. 완료 기준 작성·배정

    ‘고객 포털 출시’의 기준·배정 버튼으로 요구사항 승인, 화면 검증, 배포 확인의 담당자를 확인합니다. 관리자만 항목을 작성·분배합니다.

  3. 편하게 보고

    진행 보고에서 ‘요구사항은 끝냈고 화면은 손보는 중이야. 배포는 내일 할 예정이야.’를 입력합니다. Rocket.Chat에서도 프로젝트 → 항목 선택 후 같은 문장을 입력할 수 있습니다.

  4. 기존 양식 확인·확정

    업무목록·날짜·프로젝트별 번호와 상태가 정리된 초안을 확인합니다. 확정하면 요구사항만 체크되고 전체 진행률은 33.3%가 됩니다.

  5. 완료·재개 확인

    나머지 두 항목을 완료로 보고하고 확정하면 100%·완료가 됩니다. 항목 하나를 진행 중으로 다시 보고하면 체크가 해제되고 66.7%가 됩니다.

  6. 프로젝트별 통계 확인

    진행 통계에서 완료 기준 달성과 담당자별 예정·진행·완료 수를 확인합니다. ‘시연 · 문서 자동화’로 바꾸면 별도 업무·통계가 표시됩니다.

운영 원칙

업무 원본은 Outline입니다. 완료 기준이 있는 업무는 완료 항목 수 ÷ 전체 항목 수로 진행률을 계산합니다. 진행 중인 항목에 임의의 부분 점수를 주지 않습니다. 일반 사용자는 배정된 항목만 포털·봇에서 변경하고, 관리자는 원문 편집·기준 분배도 할 수 있습니다.

동시에 Outline 원본이 바뀌면 이전 제안의 확정을 중단합니다. 원본을 확인하고 새 제안을 만드세요.

계정은 Authentik에서 관리합니다. 업무 사용자는 work-assistant-users, 관리자는 두 그룹 모두에 속해야 합니다. 업무 그룹 등록 후 Outline 계정을 자동으로 준비합니다. Rocket.Chat은 첫 SSO 로그인 때 계정이 만들어집니다.

언제 반영되나요?
이름은 이 탭을 열거나 새로고침(F5), ‘계정 변경사항 반영’을 누르면 업데이트됩니다. 이용 중지와 서비스 이용 권한 변경은 자동으로 확인해 처리합니다.
신규 직원은 Authentik의 업무 사용자 그룹에 등록하면 Outline 계정이 준비됩니다. Rocket.Chat 계정은 직원이 처음 통합 로그인할 때 만들어집니다.

그룹 자동 연결 · 선택 사항
Outline에서 팀원을 직접 관리한다면 이 기능은 사용하지 않아도 됩니다.
Authentik 그룹을 연결하면 전용 Outline 그룹이 만들어집니다. 이후 Authentik 그룹에 직원을 추가하거나 빼면, 연결된 Outline 그룹에도 반영됩니다.
프로젝트 접근 권한은 Outline 컬렉션에서 설정합니다.
연결된 그룹
    연결된 그룹의 팀원은 Authentik에서 관리하세요. 기존 Outline 그룹과 개별 사용자에게 지정한 권한은 이 기능으로 변경되지 않습니다.

    또는 기존 Outline 컬렉션을 선택하세요.

    완료 기준 작성·분배
    항목별 담당자와 상태를 선택하세요.
    담당자·진행률 안내
    이 프로젝트에 접근할 수 있는 직원만 선택할 수 있습니다. 신규 직원은 Authentik 업무 그룹 등록·계정 동기화 후 Outline 프로젝트 권한을 부여하세요.
    진행률 = 완료 항목 수 ÷ 전체 항목 수
    항목 추가·삭제 시 전체 진행률도 바뀝니다.
    

    업무 등록
    등록하면 선택한 프로젝트의 업무 목록 아래에 업무 문서가 생성됩니다.
    

    업무 일정 조정
    계획한 작업 기간입니다. 변경 내용을 검토하고 확정하면 Outline에 반영됩니다.
